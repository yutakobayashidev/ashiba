# Native reverse engineering

Enter the dev shell from the project root before starting the agent. Use the
project-local ghidra-cli skill for command semantics. Keep the original binaries
unchanged; record hashes, evidence and analysis notes separately. Distinguish
observed code and behavior from hypotheses. Check job results before retrying
mutations after a timeout. Stop the project bridge before opening the same
Ghidra database in the GUI or changing runtime versions.
